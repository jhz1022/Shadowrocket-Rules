# Mac App Store 获取剪映专业版提示地区不可用

2026-11-12，排行榜能显示剪映专业版，点「获取」后却提示当前国家或地区不可用。Mac App Store 日志显示获取请求发往 `p20-buy.itunes.apple.com`，服务器返回了取消获取的错误。当时的配置会让这个主机命中 `apple.com` 的代理规则。

保持小火箭开启，给这个主机临时加上精确直连后，剪映开始下载。重试时 App Store 日志里仍是同一个主机；当次没有小火箭连接日志可核对出口。共享配置据此收录 `DOMAIN,p20-buy.itunes.apple.com,DIRECT`。iPhone 如果请求同一主机也会匹配，手机上的下载流程尚未实测。
